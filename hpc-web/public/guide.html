🛠️ Device Setup & Certificate Installation Instructions

Android Phone, Tablet & Smart TV Setup

অ্যান্ড্রয়েড ডিভাইসে অ্যাপ ও সার্টিফিকেট সেটআপ করার নিয়মাবলী:

  • 1

    Download Certificate & APK

    Download rootCA.crt and either Jetpack App (jetpack.apk) or Tauri App (tauri.apk) from the buttons above.

  • 2

    Install Root Certificate in Android

    Open Settings ➔ search for "Certificate" (or go to Security ➔ More security settings ➔ Encryption & credentials).

    Tap "Install a certificate" ➔ tap "CA certificate" (tap "Install anyway" if prompted) ➔ select the downloaded rootCA.crt file.

  • 3

    Install the HPC Application

    Open your Files / Downloads app, tap jetpack.apk or tauri.apk, allow "Install from this source" when prompted by Android, and tap Install.

  • 4

    Launch and Connect

    Open the app or browse to the clinic URL in Chrome. You will see a verified secure padlock 🔒 with zero warnings!

Windows 10 & 11 Computers Setup

ডাক্তার, রিসেপশন ও ক্যাশিয়ার কম্পিউটারে সার্টিফিকেট ও অ্যাপ সেটআপ:

  • 1

    Download rootCA.crt & Desktop App

    Download rootCA.crt and tauri.exe (or tauri.msi installer) from above.

  • 2

    Import into Trusted Root Store

    Double-click the downloaded rootCA.crt ➔ click Install Certificate...

    Choose Current User (or Local Machine) ➔ choose "Place all certificates in the following store" ➔ click Browse... ➔ select "Trusted Root Certification Authorities" ➔ click OK ➔ Next ➔ Finish.

  • 3

    Confirm Security Warning

    When the Windows Security prompt asks to trust "HPC Local Root CA", click Yes.

  • 4

    Run Desktop App or Browser

    Launch tauri.exe or reload the web portal in Chrome/Edge/Brave for full, secure, seamless access.

Apple iPhone & iPad (Safari)

আইফোন ও আইপ্যাডে সার্টিফিকেট ইনস্টলেশন প্রক্রিয়া:

  • 1

    Download Profile in Safari

    Open Safari on your iPad/iPhone, tap Download rootCA.crt, and tap "Allow" when prompted to download a configuration profile.

  • 2

    Install Downloaded Profile

    Open Settings ➔ tap "Profile Downloaded" ➔ tap Install in the top-right corner. Enter device passcode.

  • 3

    Enable Full Root Trust (Important!)

    Navigate to:

    Settings ➔ General ➔ About ➔ Certificate Trust Settings

    Under "Enable full trust for root certificates", switch ON "HPC Local Root CA" and tap Continue.

Linux (Ubuntu / Debian) Terminal

লিনাক্স সিস্টেমে সার্টিফিকেট ট্রাস্ট স্টোরে যুক্ত করার কমান্ড:

  • 1

    Copy Certificate to System Store

    sudo cp rootCA.crt /usr/local/share/ca-certificates/hpc-rootCA.crt
  • 2

    Update System CA Bundle

    sudo update-ca-certificates
